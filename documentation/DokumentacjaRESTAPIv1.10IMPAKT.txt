1.​ Opis technologii
API systemu etrade.pl zostało zrealizowane według wzorca REST.
Komunikacja polega na wysyłaniu żądania HTTP pod adres: https://api.etrade.pl/.
Odpowiedź zwracana jest w formacie JSON.

2.​ Autoryzacja
Każde żądanie w API wymaga uwierzytelnienia. Uwierzytelnienie następuje poprzez wysłanie nagłówka
Authorization: Basic.
Sugestia: Dzięki nowemu systemowi zarządzania uprawnieniami powinieneś utworzyć użytkownika API
któremu przydzielisz uprawnienia tylko do części systemu z których będziesz korzystać.
Dzięki bezpiecznemu połączeniu (https) logowanie przy pomocy Http Basic-Auth jest bezpieczne i proste
w użyciu.
Przykład implementacji:
​
Linux:
curl -u ADMIN:admin1 "https://api.etrade.pl/v1/products"
PHP:
<?php
$username='ADMIN';
$password='admin1';
$url ='https://api.etrade.pl/v1/products'
$ch = curl_init();
curl_setopt($ch, CURLOPT_URL, $url);
curl_setopt($ch, CURLOPT_RETURNTRANSFER,1);
curl_setopt($ch, CURLOPT_HTTPAUTH, CURLAUTH_ANY);
curl_setopt($ch, CURLOPT_USERPWD, "$username:$password");
$result = curl_exec($ch);
curl_close ($ch);
