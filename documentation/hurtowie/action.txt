Nagłówki HTTP:

ActionCustomerId - Id klienta w Action
ActionUserName - login konta do platformy iserwis, z którego będa pobierane pliki
ActionXmlAuthKey - unikalny klucz uwierzytelniający (do wygenerowania w is3.action.pl/dataexchange)
Poniżej znajduje się przykład zapytania cUrl do pobrania cenika z nagłówkami uwierzytelniającymi:

                curl -X GET \
                    [URL CENNIKA] \
                    -H 'ActionCustomerId: [CUSTOMER_ID]' \
                    -H 'ActionUserName: [LOGIN]' \
                    -H 'ActionXmlAuthKey: [UNIQUE_KEY]' 
            
Parametry Query String:

ActionCustomerId - Id klienta w Action
ActionUserName - login konta do platformy iserwis, z którego będa pobierane pliki
ActionXmlAuthKey - unikalny klucz uwierzytelniający (do wygenerowania poniżej)
Przykład:

                [URL CENNIKA]?ActionCustomerId=[CUSTOMER_ID]&ActionUserName=[LOGIN]&ActionXmlAuthKey=[UNIQUE_KEY]
            
Dane uwierzytelniające muszą być URL ENCODED
